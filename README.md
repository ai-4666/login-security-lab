# 웹 로그인 시스템의 보안 취약점 분석 및 개선

Python 표준 라이브러리와 SQLite로 만든 **로컬 실습용** 비교 실험입니다. 사용자 입력을 SQL 문자열에 직접 연결하는 방식과 매개변수화 쿼리 방식을 비교합니다.

## 실행
Python 3.10 이상에서 추가 패키지 없이 실행합니다.

```sh
python3 lab.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 서버는 루프백 주소에만 연결됩니다. 종료는 Ctrl+C입니다. 정상 가상 계정은 `student / demo-pass`입니다.

## 실험 재현
```sh
python3 experiment.py
```

8개 입력 조건을 두 구현에 각각 적용하여 16개 결과를 생성합니다. 결과는 [CSV](results/results.csv), [JSON](results/results.json)에 저장됩니다. 기존 결과를 덮어쓰므로 별도 보관이 필요하면 복사하세요.

- [탐구 보고서](docs/report.md)
- [활동지 1~5번 작성 자료](docs/worksheet.md)
- [처리 흐름도](docs/design.md)

## 범위와 한계
직접 만든 메모리 데이터베이스와 가상 계정만 사용합니다. 취약한 구현은 문제 관찰을 위해 의도적으로 포함했습니다. 외부 서버에 공개 배포하거나 실제 계정 정보를 입력하지 마세요.

이 실험은 SQL 처리 방식만 분리하여 비교합니다. 두 구현 모두 실험 변인 통제를 위해 가상 비밀번호를 평문으로 저장하며, 실제 서비스에 필요한 비밀번호 해시, 세션, TLS, CSRF 방어, 로그인 횟수 제한 등은 구현하지 않았습니다. ‘secure’는 이 실험의 SQL 처리 방식 이름이며 전체 인증 시스템의 안전성을 뜻하지 않습니다.

자료와 코드는 Codex가 생성하고 실행하여 검증한 산출물입니다. 학생의 실제 참여·팀 협업·과거 활동을 증명하는 자료가 아닙니다. 활동지는 직접 재현하고 이해한 범위에 맞게 작성하세요.
